# فلش‌کارت فصل ۱ زیست‌شناسی دهم — دنیای زنده

| روی کارت: پرسش | پشت کارت: پاسخ |
|---|---|
| زیست‌شناسی چه چیزی را مطالعه می‌کند؟ | جانداران و فرایندهای زیستی را به روش علمی بررسی می‌کند. |
| نگرش کل‌نگر چیست؟ | بررسی سامانه با توجه به اجزا و ارتباط میان آن‌ها. |
| هم‌ایستایی چیست؟ | تنظیم شرایط درونی در محدوده‌ای مناسب با وجود تغییرات محیط. |
| رشد با نمو چه تفاوتی دارد؟ | رشد افزایش اندازه یا جرم است؛ نمو تغییر کیفی یا گذر از مراحل زندگی است. |
| هفت ویژگی حیات کدام‌اند؟ | نظم و سازمان‌یافتگی، هم‌ایستایی، رشد و نمو، دریافت و استفاده از انرژی، پاسخ به محیط، تولیدمثل و سازش با محیط. |
| جمعیت چیست؟ | افراد یک گونه در زمان و مکان مشخص. |
| اجتماع چیست؟ | مجموعهٔ جمعیت‌های گونه‌های مختلف که با هم تعامل دارند. |
| بوم‌سازگان چیست؟ | اجتماع جانداران به‌علاوهٔ عوامل غیرزنده و برهم‌کنش‌هایشان. |
| زیست‌کره چیست؟ | مجموع نواحی زمین که حیات در آن‌ها وجود دارد. |
| واحد سازندهٔ پروتئین چیست؟ | آمینواسید. |
| واحد سازندهٔ نوکلئیک اسید چیست؟ | نوکلئوتید. |
| نقش اصلی ریبوزوم چیست؟ | ساخت پروتئین. |
| نقش دستگاه گلژی چیست؟ | تغییر، مرتب‌سازی و بسته‌بندی برخی مواد. |
| انتشار ساده در چه جهتی است؟ | در جهت شیب غلظت، بدون مصرف مستقیم انرژی یاخته. |
| انتشار تسهیل‌شده چیست؟ | عبور در جهت شیب غلظت با کمک پروتئین غشایی. |
| اسمز چیست؟ | انتشار خالص آب از غشای دارای تراوایی انتخابی. |
| انتقال فعال چه ویژگی دارد؟ | به پروتئین انتقالی و انرژی نیاز دارد و می‌تواند برخلاف شیب باشد. |
| چهار بافت اصلی بدن کدام‌اند؟ | پوششی، پیوندی، ماهیچه‌ای و عصبی. |
| کارکرد اصلی بافت عصبی چیست؟ | دریافت، پردازش و انتقال پیام‌های عصبی. |
| کارکرد اصلی بافت ماهیچه‌ای چیست؟ | انقباض و ایجاد نیرو و حرکت. |

## روش مرور پیشنهادی
- ابتدا فقط ستون پرسش را بخوانید و پاسخ را از حافظه بازیابی کنید.
- کارت‌های دشوار را جدا کنید و همان روز دوباره مرور کنید.
- کارت‌ها را پس از ۱ روز، ۱ هفته و ۱ ماه تکرار کنید.
- پاسخ را با واژگان علمی دقیق بیان کنید؛ صرفاً حفظ‌کردن یک کلمه کافی نیست.
