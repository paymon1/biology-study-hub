# فلش‌کارت‌های فصل ۲ زیست دهم — گوارش و جذب مواد

> روش پیشنهادی: ابتدا پاسخ را بپوشانید و از حافظه بازیابی کنید؛ سپس پاسخ را بررسی کنید. کارت‌هایی که اشتباه پاسخ می‌دهید را زودتر مرور کنید.

| روی کارت: پرسش | پشت کارت: پاسخ |
|---|---|
| لولهٔ گوارش چیست؟ | مسیر پیوستهٔ عبور غذا از دهان تا مخرج |
| بنداره چه می‌کند؟ | با انقباض، عبور محتویات بین بخش‌ها را تنظیم می‌کند |
| ترتیب چهار لایه از بیرون به داخل چیست؟ | بیرونی، ماهیچه‌ای، زیرمخاط، مخاط |
| دو جهت اصلی ماهیچه در لایهٔ ماهیچه‌ای چیست؟ | حلقوی و طولی |
| ویژگی اضافی ماهیچهٔ معده چیست؟ | لایهٔ مورب |
| مخاط چه نقش‌هایی دارد؟ | ترشح، جذب و حفاظت؛ بسته به بخش لوله |
| حرکت کرمی چیست؟ | موج انقباضی که محتویات را در امتداد لوله پیش می‌برد |
| حرکت قطعه‌قطعه‌کننده چه می‌کند؟ | محتویات را مخلوط و خردتر می‌کند |
| گوارش مکانیکی چیست؟ | کاهش اندازهٔ قطعات غذا بدون شکستن مستقیم پیوندهای شیمیایی |
| گوارش شیمیایی چیست؟ | تبدیل مولکول‌های بزرگ به کوچک‌تر با کمک آنزیم‌ها |
| آمیلاز بزاقی بر چه ماده‌ای اثر می‌کند؟ | نشاسته |
| بلع در کدام بخش از مسیر آغاز می‌شود؟ | دهان؛ سپس پاسخ بلع در حلق ادامه می‌یابد |
| حرکت غذا در مری چگونه است؟ | حرکت کرمی |
| کیموس چیست؟ | مخلوط نیمه‌مایع حاصل از غذا و شیرهٔ معده |
| پپسینوژن چیست؟ | پیش‌ساز پپسین |
| پپسین چه نوع ماده‌ای را تجزیه می‌کند؟ | پروتئین‌ها |
| کلریدریک اسید معده چه نقشی دارد؟ | ایجاد محیط اسیدی و کمک به فعال شدن پپسینوژن |
| یاخته‌های اصلی غدهٔ معده چه ترشح می‌کنند؟ | پپسینوژن |
| یاخته‌های کناری معده چه ترشح می‌کنند؟ | کلریدریک اسید و عامل داخلی |
| عامل داخلی برای جذب کدام ویتامین لازم است؟ | ویتامین B₁₂ |
| مخاط و بیکربنات معده چه نقشی دارند؟ | حفاظت از سطح مخاط در برابر اسید و آنزیم |
| صفرا کجا ساخته می‌شود؟ | کبد |
| صفرا کجا ذخیره می‌شود؟ | کیسهٔ صفرا |
| آیا صفرا آنزیم دارد؟ | خیر |
| امولسیون‌سازی چربی یعنی چه؟ | پراکنده شدن قطره‌های بزرگ چربی به قطره‌های کوچک‌تر |
| فایدهٔ امولسیون‌سازی چیست؟ | افزایش سطح تماس برای عملکرد لیپاز |
| محل اصلی جذب مواد غذایی کجاست؟ | رودهٔ باریک |
| سه ساختار افزایش‌دهندهٔ سطح جذب چیست؟ | چین‌های حلقوی، پرزها و ریزپرزها |
| تفاوت پرز و ریزپرز چیست؟ | پرز برجستگی بافتی؛ ریزپرز چین میکروسکوپی غشا |
| در پرز چه دو مسیر عروقی وجود دارد؟ | شبکهٔ مویرگی خونی و مویرگ لنفی |
| بسیاری از قندهای ساده ابتدا وارد کجا می‌شوند؟ | مویرگ خونی پرز |
| فرآورده‌های لیپیدی عمدتاً ابتدا وارد کجا می‌شوند؟ | مویرگ لنفی پرز |
| سیاهرگ باب کبدی خون را به کجا می‌برد؟ | از دستگاه گوارش به کبد |
| رودهٔ بزرگ چه چیزی جذب می‌کند؟ | آب و برخی یون‌ها |
| آیا رودهٔ بزرگ پرز دارد؟ | خیر |
| بندارهٔ داخلی مخرج از چه نوع ماهیچه‌ای است؟ | صاف |
| بندارهٔ خارجی مخرج از چه نوع ماهیچه‌ای است؟ | مخطط |
| گوارش در پارامسی کجا رخ می‌دهد؟ | درون واکوئول گوارشی |
| کافنده‌تن در پارامسی چه می‌کند؟ | آنزیم‌های گوارشی را به واکوئول غذایی می‌رساند |
| هیدر چه نوع حفره‌ای دارد؟ | حفرهٔ گوارشی با یک دهانه |
| گوارش هیدر چگونه آغاز می‌شود؟ | برون‌یاخته‌ای در حفره و سپس درون‌یاخته‌ای |
| کرم کدو چگونه مواد غذایی می‌گیرد؟ | از سطح بدن؛ دستگاه گوارش ندارد |
| چینه‌دان ملخ چه می‌کند؟ | غذا را ذخیره و نرم می‌کند |
| پیش‌معدهٔ ملخ چه نقشی دارد؟ | خرد کردن مکانیکی غذا |
| سنگدان پرنده چه می‌کند؟ | آسیاب مکانیکی غذا |
| چهار بخش معدهٔ نشخوارکننده چیست؟ | سیرابی، نگاری، هزارلا، شیردان |
| میکروب‌های همزیست نشخوارکننده چه اهمیتی دارند؟ | در تجزیهٔ سلولز نقش دارند |

## برنامهٔ مرور فاصله‌دار

- روز صفر: همهٔ کارت‌ها را یک دور بخوانید و پاسخ دهید.
- روز ۱: کارت‌های دشوار و اشتباه را دوباره پاسخ دهید.
- روز ۷: کل مجموعه را بدون نگاه به پاسخ‌ها مرور کنید.
- روز ۳۰: کارت‌های دشوار را با پرسش‌های ترکیبی تمرین کنید.
