# فلش‌کارت‌ها

فلش‌کارت‌ها باید کوتاه، دقیق و مناسب بازیابی فعال باشند. هر کارت ترجیحاً یک مفهوم را بسنجد؛ پاسخ‌ها نباید مبهم یا چندپهلو باشند.

برای هر مجموعه، پایه، فصل، موضوع، منبع، تعداد کارت‌ها و تاریخ بازبینی را ذکر کنید. از کپی‌کردن مجموعه‌های دارای حق نشر بدون اجازه خودداری کنید.
