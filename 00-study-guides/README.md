# راهنمای مطالعه

راهنمای شروع، روش مطالعهٔ زیست‌شناسی، خواندن دقیق متن و شکل کتاب، یادداشت‌برداری، مرور فعال، مدیریت زمان و راهبردهای آزمون در این بخش قرار می‌گیرد.

پیشنهاد موضوع‌ها:
- چگونه یک فصل زیست‌شناسی را مطالعه کنیم؟
- مرور فاصله‌دار و بازیابی فعال
- تحلیل گزینه‌ها و مدیریت زمان
- برنامه‌ریزی واقع‌بینانه برای امتحان مدرسه و کنکور

راهنماها توصیهٔ آموزشی‌اند، نه تضمین نتیجه. برای قوانین آزمون هر سال به اطلاعیهٔ رسمی مراجعه کنید.
