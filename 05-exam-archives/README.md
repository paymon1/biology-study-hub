# آرشیو آزمون‌ها و منابع آزمونی

این بخش فهرست و پیوند آزمون‌های مدرسه، امتحانات نهایی و کنکور را نگه می‌دارد.

برای هر مورد، سال، نوبت، نوع آزمون، مرجع انتشار و پیوند منبع اصلی ثبت شود. فایل آزمون یا پاسخ‌نامه را فقط زمانی در مخزن قرار دهید که مجوز بازنشر آن روشن باشد؛ در غیر این صورت به صفحهٔ رسمی ناشر پیوند دهید.

اطلاعات مربوط به ضوابط، منابع و تغییرات سال جاری باید از اطلاعیه‌های رسمی بررسی شود.
